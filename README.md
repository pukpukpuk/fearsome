# Fearsome

The client-side mod required to play Fear: GOTY Edition. It provides the game's interface: HUD, menus, character and perk descriptions, and visual effects.

## Installation

### Automatic

Install [Fearsome Sentinel](https://github.com/pukpukpuk/fearsome-sentinel): it downloads Fearsome with all of its dependencies and keeps them up to date.

### Manual

1. Install Fabric for Minecraft 1.21.11.
2. Put these mods into mods folder:
   - Fearsome from [Releases](https://github.com/pukpukpuk/fearsome/releases)
   - [Fabric API](https://modrinth.com/mod/fabric-api)
   - [owo-lib](https://modrinth.com/mod/owo-lib)
