# Fearsome

Клиентский мод, необходимый для игры в Fear: GOTY Edition. Он отвечает за интерфейс игры: HUD, меню, описания персонажей и перков, а также визуальные эффекты.

## Установка

### Автоматическая

Установите [Fearsome Sentinel](https://github.com/pukpukpuk/fearsome-sentinel): он скачает Fearsome со всеми зависимостями и будет поддерживать их в актуальном состоянии.

### Ручная

1. Установите Fabric для Minecraft 1.21.11.
2. Положите в папку с модами:
   - Fearsome из [Releases](https://github.com/pukpukpuk/fearsome/releases)
   - [Fabric API](https://modrinth.com/mod/fabric-api)
   - [owo-lib](https://modrinth.com/mod/owo-lib)
